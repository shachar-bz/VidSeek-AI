# VidSeek AI promo video

A ~100 second ad for VidSeek AI, built with [Remotion](https://www.remotion.dev/). It
mixes AI-made frames (the hook) with real recordings of the product.

## Story

1. **Hook (0–17 s):** Alex tries a 900-page book, a chatbot's wall of text and a two-hour
   video, and each one frustrates him. It ends on "What if Alex could just… ask the video?"
2. **Reveal (17 s):** the music drops and the logo lands.
3. **Product (19–83 s):**
   * five real "Find video" clicks on five sites
   * ask anything (YouTube)
   * click a timestamp to jump (Coursera)
   * the comments (YouTube)
   * follow-up questions (TED)
   * the visual agent finding the whisking at 08:39 (Internet Archive)
   * a formula lifting off a lecture slide (Panopto)
   * Alex's tagged library
4. **Close:** Alex gets it in seconds, then the end card: "Ask any video anything.", built
   by Shachar Ben Zur.

## Setup

```bash
npm install
```

Media that is not in git (see `.gitignore`):

* `public/clips/`: the raw recordings from `promo-video/videos/` in the main checkout,
  plus `ia_whisk.mp4`. That file is 8:34–8:50 of the Internet Archive cooking show,
  downloaded with
  `yt-dlp --download-sections "*8:34-8:50" https://archive.org/details/TheVistaGroup-2004TVBroadcastFoodNetworkCookingSchoolwithCommercials`.
* `public/stills/`: library screenshots of the Alex Levi demo account, taken at
  1600×900 @2x, and the AI stills of Alex.
* `public/audio/`: generated by the scripts below.

## Generating media (ElevenLabs)

The key is read from `ELEVENLABS_VIDEO` in `.env`, either here or in the main checkout's
`promo-video/.env`.

```bash
python scripts/generate_voiceover.py     # narration, one file per line in voiceover_lines.json
python scripts/generate_music.py         # music_hook (tense bed) + music_main (starts on the drop)
python scripts/generate_sound_effects.py
python scripts/generate_ai_stills.py     # needs the key's "Image & Video" permission
```

The timeline in `src/timeline.ts` holds every narration start and every scene boundary.
The main music cue is 120 BPM, so beats land every 0.5 s after 17 s.

When the four AI stills exist, set `AI_STILLS_AVAILABLE = true` in `src/timeline.ts`. The
hook then shows Alex behind the floating UI.

## Preview and render
