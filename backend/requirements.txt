# --- conversation tools module ---

# --- azure postgresql module ---
# Remove this block together with backend/storage/postgres/ if the module is dropped.
# Everything about a video that is not its bytes: the videos, transcript_segments and
# comments rows, and the migrations that create them. Spoken to over the ordinary Postgres
# wire protocol, so no Azure-specific package exists or is needed. `binary` avoids needing
# a local libpq and a C compiler on Windows; `pool` is psycopg_pool, which keeps one
# connection warm across jobs. 3.1 is the floor because everything here uses psycopg 3's
# API (`connection.execute(...)` returning a cursor, and `psycopg.sql` composition).
# Needs AZURE_DATABASE_URL in backend/.env, and
# `python -m backend.storage.postgres.migrate` run once against the server.
psycopg[binary,pool]>=3.1
python-dotenv
# --- end azure postgresql module ---
